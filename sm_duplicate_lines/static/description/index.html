Duplicate Lines

Duplicate any row in Sale Orders, Purchase Orders & Invoices with a single click

Module Video Overview

Features

1 One-click duplicate

A small copy icon appears on each row of your order lines. Click it once and the entire row is duplicated instantly — no dialogs, no extra steps. Works on both saved and unsaved lines.

2 Sale Orders

Quickly duplicate order lines in Sale Orders. Product, quantity, unit price, taxes, description — everything is copied accurately. Great for repetitive quoting.

3 Purchase Orders

Same one-click experience on Purchase Orders. Duplicate vendor lines instantly to speed up procurement and purchase planning.

4 Invoices & Bills

Duplicate invoice lines on Customer Invoices, Vendor Bills, Credit Notes — any document based on account.move. Accounts, taxes, and analytic tags are all preserved.

5 Smart field handling

Automatically handles all field types: Many2one, Many2many, One2many, Date, Datetime, monetary, and more. Fields marked copy=False in Python are respected — no accidental data leakage.

And much more...

Saved & Unsaved

Works on both persisted records (uses server-side copy_data()) and brand-new unsaved rows (client-side duplication).

Opt-Out Per Field

Add disable_lines_duplicate="1" to any x2many field in XML to hide the copy button on that specific field.

Lightweight

Only depends on the web module. No extra Python dependencies, no database changes, no cron jobs. Pure JS + minimal Python patch.

Respects copy=False

Each field’s Python copy attribute is checked. Fields with copy=False are automatically skipped during duplication.

No Onchange Conflicts

Onchange methods are suppressed during duplication to prevent them from overwriting the copied values.

Print Friendly

The copy button column is automatically hidden when printing. No extra clutter in your printed documents.
